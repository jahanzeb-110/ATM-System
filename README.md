# ATM System

A Python console-based ATM System created to practice **Object-Oriented Programming (OOP)** and core Python concepts.

The project simulates basic ATM operations such as depositing money, withdrawing money, checking balance, changing PIN, and viewing transaction history.

## Features

* Create an ATM account
* PIN verification
* Deposit money
* Withdraw money
* Check balance
* Fast cash
* Change PIN
* Transaction history
* Mini statement
* 3 login attempts
* Account withdrawal limit

## Python Concepts Used

* Classes and Objects
* Constructor
* Object Attributes
* Methods
* Lists
* Conditional Statements (`if-elif-else`)
* Loops
* Exception Handling (`try-except`)

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python Atm.py
```
